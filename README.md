# AI-Ready Task Manager

A FastAPI task management API with authentication, protected CRUD routes, validation, testing, background tasks, CORS, and Swagger documentation.

## Features

- User registration
- JWT login
- Protected user profile
- Create tasks
- List only your own tasks
- Get a task by ID
- Partial task updates
- Delete tasks
- User ownership protection
- Custom 404 and 409 errors
- Background task notification
- Mock AI suggestion endpoint
- Swagger and ReDoc documentation
- Pytest tests with an isolated SQLite test database
